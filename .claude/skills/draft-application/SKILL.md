# Draft application material

## Cover note

- 150 to 200 words, three paragraphs: the fit, the evidence, the close.
- Paragraph 2 carries two proof points from `positioning.md`, each tied to a named
  requirement in the posting.
- Same voice rules as outreach. It must not repeat the outreach email's sentences.

## Resume tweaks

A list of 3 to 6 concrete edits to the existing resume, each with:

- `section`: where the edit goes (Summary, an Experience entry, Capabilities).
- `change`: one of `reorder`, `reword`, `emphasise`, `trim`.
- `detail`: exactly what to do, for example: move the AI digital human bullet to
  first position under SpringCT.
- `why`: the posting requirement this serves.

## Rules

- Tweaks reorder, reword or trim what exists. They never add experience, tools,
  titles or numbers that are not in `profile.md`.
- Mirror the posting's vocabulary only where it truthfully describes the work.
- If the posting asks screening questions, list them under `screening_questions` with
  a 2-sentence suggested answer each. Otherwise leave it as an empty list.
