# Draft an outreach email

The email is a draft for the person to review, edit and send themselves.

## Shape

- **Subject**: under 8 words, names the role. No "Quick question" or "Application".
- **Body**: 90 to 130 words, four short parts.
  1. **Why them**: the `hook` from research, in one sentence. If `hook` is null,
     open with the role and the problem it exists to solve.
  2. **Why me**: one proof point from `positioning.md` that matches the role's main
     responsibility. Name the project and the result.
  3. **Second proof, optional**: only if it covers a different requirement.
  4. **Ask**: one low-effort request, such as a 20-minute call or the right person
     to speak to. Mention that an application has been or will be submitted.
- **Sign-off**: the person's name, then website or LinkedIn from the profile.

## Rules

- Follow the voice rules in `positioning.md` exactly, including banned words.
- Use only facts stated in `profile.md`. Never round a metric up or add a number.
- If the role has a known gap from `positioning.md` (for example no formal PM title),
  do not hide it and do not apologise. Frame what was actually owned.
- No more than one sentence about the company. The email is about fit.
- No placeholders like "[Name]". If the contact's name is unknown, start with "Hello,".
- Every email must differ in opening and proof point from the other drafts in the same run.

## Self-check before saving

Read the draft once as the recipient. Remove any sentence that could be sent
unchanged to a different company.
